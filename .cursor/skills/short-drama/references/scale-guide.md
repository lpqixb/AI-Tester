# 体量自动判断指南

根据用户一句话的信息密度与叙事野心选择体量，**默认偏短**，避免注水。

## 判定表

| 信号 | 判定 | 规模 |
| --- | --- | --- |
| 单一场景、一个冲突、要「一小段」「一条」 | 单场微短剧 | 1 场，8–12 镜 |
| 有明确开端–高潮–结局，但未提「几集」 | 标准单集 | 1–3 场，12–18 镜 |
| 提到「连载」「多集」「第一季」「爽文长剧情」、多阶段逆袭 | 迷你剧 | 3–5 集，每集 6–10 镜 |
| 信息极少（如「霸总甜宠」） | 标准单集 | 12–15 镜，自行补全完整弧光 |
| 明确要求「3 集」「5 集」等 | 从其数量 | 每集 6–10 镜 |

## 决策流程

```
用户原话
  ├─ 含明确集数？ → 按集数生成迷你剧
  ├─ 多阶段人生/多年跨度/多重反转？ → 迷你剧 3–5 集
  ├─ 单冲突、单场景？ → 单场微短剧
  └─ 其他 → 标准单集
```

## 写入文档

在文件头「体量判定」一行写清类型与理由，例如：

> 体量判定：标准单集 — 用户未指定集数，但需要完整起承转合，采用 14 镜单集。

## 上限

- 单次生成不超过 **5 集**、总镜数不超过 **50**。  
- 用户要更长时：先交付前 3–5 集结构，并在回复中说明可再调用 Skill 续写后续集。
