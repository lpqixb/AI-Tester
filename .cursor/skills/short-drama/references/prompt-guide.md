# 静帧与视频提示词规范

每一镜输出 **两套** 提示词，视觉设定必须同源（同一人、同一服装、同一场景色调）。

## 共同原则

1. **角色锚点复用**：从人物小传复制固定短语，例如  
   `25岁女性，黑色齐肩发，米色风衣，左手银戒`  
   不要每镜重新发明外貌。
2. **场景锚点**：地点 + 时间 + 光线（如「雨夜霓虹便利店冷白灯」）。
3. **风格词克制**：选 1–2 个主风格（电影感、短剧竖屏、赛博等），避免堆砌矛盾词。
4. **竖屏短剧默认**：未指定时默认 `vertical 9:16, short-drama cinematic`。
5. **安全**：不写真实名人脸、不涉及未成年人色情/性化。

## 静帧提示词（Image）

面向 Midjourney / Flux / SD 等。侧重**构图定格**。

建议结构：

```
[主体与外观锚点], [动作定格], [环境与光线], [景别], [风格], [画幅]
```

示例：

```
25岁亚洲女性，黑色齐肩发，米色风衣，左手银戒，站在雨夜便利店门口回望，
霓虹倒映积水，中景，电影感冷暖对比光，短剧竖屏 9:16，高清
```

英文可附在同一代码块下一行，便于部分工具：

```
young Asian woman, shoulder-length black hair, beige trench coat, silver ring on left hand,
looking back at rainy convenience store entrance, neon reflections in puddles,
medium shot, cinematic lighting, vertical 9:16
```

## 视频提示词（Video）

面向 Kling / Runway / 可灵等。侧重**动作与镜头运动**，并与静帧一致。

建议结构：

```
[主体与外观锚点], [连贯动作], [镜头运动], [环境动态], [节奏/时长感], [画幅与风格]
```

示例：

```
同一位25岁女性（黑齐肩发、米色风衣、左手银戒）在雨夜便利店门口缓缓转身回望，
镜头自中景缓慢推近至近景，雨水斜落，霓虹灯牌轻微闪烁，时长约4秒，
短剧竖屏 9:16，电影感
```

## 分镜之间的提示词衔接

| 上一镜结尾 | 下一镜开头应呼应 |
| --- | --- |
| 人物走出画右 | 下一镜自画左入画或同向跟随 |
| 特写眼神看向某处 | 下一镜主观镜头或被视对象 |
| 放下杯子 | 下一镜杯仍在桌上同位置（除非剧情拿走） |
| 硬切反转 | 在「衔接说明」中写明动机，提示词可突变但角色锚点仍稳定 |

## 禁止

- 同一角色相邻两镜发型/服装无剧情理由地突变  
- 只有形容词、没有具体动作的视频提示词（如只写「很美很虐」）  
- 把整段剧本粘进提示词（提示词要可执行，宜短于 80–120 词量级）
