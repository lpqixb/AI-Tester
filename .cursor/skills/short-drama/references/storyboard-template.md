# 故事板输出模板

Agent 生成的 Markdown **必须**按下列结构组织（可按体量省略「分集大纲」）。用中文撰写叙述部分；提示词可中英并用。

```markdown
# {短剧标题}

> 生成时间：YYYY-MM-DD HH:mm:ss (Asia/Shanghai)
> 用户原意：{用户原话摘要}
> 体量判定：{单场微短剧 | 标准单集 | 迷你剧 N 集} — {一句理由}

## 创作说明

- 风格：{类型 / 情绪}
- 假设补全：{列出 Agent 自行补全的设定}
- 目标时长感：{如约 60–90 秒 / 每集约 45 秒}

## 一句话卖点

{20 字以内钩子}

## 故事梗概

{300–600 字，起承转合完整，迷你剧写清跨集主线}

## 人物小传

### {角色名}（主角）

- 身份：
- 外观锚点：（发型、年龄感、服装主色、标志物 — 供提示词复用）
- 性格：
- 欲望 / 秘密：

### {角色名}（配角）

- …

## 分集大纲

（仅迷你剧需要；单集可写「本篇为单集，无分集」。）

- 本集事件：
- 结尾钩子：

### 第 2 集 · …
```

```
## 连续性检查清单

- [ ] 角色外观锚点跨镜一致
- [ ] 关键时间线与昼夜合理
- [ ] 道具出现与消失有交代
- [ ] 分镜衔接说明齐全
- [ ] 每镜均有静帧 + 视频双提示词

## 使用建议

- 静帧：可用于 Midjourney / Flux 等先定画面。
- 视频：可用于 Kling / Runway / 可灵等；建议先用静帧锁定角色再图生视频。
```

## 字段填写要求

| 字段 | 要求 |
| --- | --- |
| Shot 编号 | `Shot 01` 起，两位数字，全集或单集内连续 |
| 衔接上一镜 | 禁止空白；说明动作、视线、声音或硬切动机 |
| 静帧 / 视频提示词 | 同一镜角色描述必须同源，避免「换脸」 |
| 对白 | 短剧节奏：单句宜短，可留白 |
