# 连续性与分镜衔接规则

短剧观感依赖「上一镜如何接到下一镜」。生成故事板时强制遵守下列规则。

## 叙事连续性

1. **因果链**：每一场的结果应成为下一场的前提；禁止无动机跳跃。  
2. **时间线**：标注大致时间（清晨 / 傍晚 / 三天后）；闪回须在故事板标明「闪回」。  
3. **信息揭露节奏**：秘密分镜逐步释放，避免开场倾倒全部设定。  
4. **情绪曲线**：相邻镜情绪可递进或反转，反转须有剧情触发点。

## 视觉连续性

1. **角色锁定**：外观锚点全文统一；换装必须有场次说明。  
2. **道具**：关键道具（信、戒指、手机）入画与离画要有镜头交代。  
3. **空间**：同一场景内左右关系稳定（轴线）；越轴须有意为之并写在衔接说明。  
4. **天气 / 光线**：无转场说明时保持一致。

## 衔接写法（「衔接上一镜」字段）

每镜必填，推荐句式：

- `承接 Shot 0N 结尾的{动作/视线/声音}，本镜以{景别}展示{结果}`  
- `声音桥：上一镜门铃声延续至本镜室内`  
- `硬切：用突然静音制造反转，动机是{…}`

开场镜写：`开场 — 建立{时空}与{主角状态}`。

## 自检表（保存前）

- [ ] 任意抽出相邻两镜，口头能说清「为什么接得上」  
- [ ] 主角在 Shot 01 与最后一镜外观锚点一致（或有换装场）  
- [ ] 无「幽灵道具」（上一镜没有、下一镜突然拿着）  
- [ ] 迷你剧每集结尾有钩子，下集开头有回收或延续  
- [ ] 每镜静帧与视频提示词描述的是同一瞬间/同一动作链条
